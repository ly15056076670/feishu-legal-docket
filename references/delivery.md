# 送达平台下载与落盘前校验

承接原始 `court-doc-extract` 包的 `sms-patterns.json` 平台清单与 `download_validator.py`。当前包**实际封装的自动 API 下载仅覆盖全国法院统一送达平台 `zxfw.court.gov.cn`**；其余平台保留原包识别规则，使用当前会话已经具备的交互浏览器、人工登录/下载后再校验，不宣称脚本支持。平台接口随时可能调整，以当次真实响应为准。

## zxfw 下载

可以先将用户这次提供的短信正文交给 `python3 scripts/sms_delivery.py` 的标准输入。输出只有识别的平台和下载方式。收到的完整原始链接和签名参数只在执行期间使用。

用户提供完整原始 HTTPS 送达链接，从 URL（含 `#` 后参数）提取 `qdbh`、`sdbh`、`sdsin`。`scripts/court_download.py` 只接受该域名，向原包记录的 `getWsListBySdbhNew` 接口提交这些参数，逐条读取 `data[].wjlj`；该接口的成功码已见到 `0` 和实际返回的 `200`，两者都仍须有非空文书列表，其他状态拒绝下载。只允许公共 HTTPS 文件链接，限制响应体大小。每份响应先检查 `%PDF`、大小和内容类型，再用 `pypdf` 打开并确认有页面，通过后写入私有临时目录。

整批文书验证完毕后才发布正式 PDF。已有同名且字节相同的普通文件可直接复用，已知冲突则在发布新文件前停止。使用支持硬链接的本地输出目录，以便发布时保证单份文件完整且不覆盖。异常中断后可用同一输入重试，复用此前已发布且内容相同的文件。

运行：

```bash
# agent 从用户提供的原始链接通过 stdin 传入；避免把送达参数放进命令行或日志
python3 scripts/court_download.py --link-stdin --output-dir '<本次案件的授权目录>'
# 输入是一整条短信时，改用 --sms-stdin。识别到多个不同链接时先选定其中一个。
# 若律师已确认真实收到日，才可追加 --received-date YYYY-MM-DD
```

在实际执行环境将链接作为该命令的标准输入；不得直接将含身份参数的 URL 输出到聊天、命令输出或持久日志。输出 JSON 给出保存路径、文书名称、平台原始记录时间；不返回签名下载 URL。没有确认收到日时保存 `_收到时间待确认.pdf`，`dt_cjsj` 不作为确认日。下载的文件再逐页读取，扫描件先 MinerU；只有成功验真的原件能上传飞书附件。

## 其他平台及阻塞

- 广东 `sd.gdems.com`、集约 `jysd.10102368.com`、司法送达网 `sfpt.cdfy12368.gov.cn`：原包为浏览器路径，没有本包内的 API 下载脚本。湖北免账号接口原包仅记录了可能需要验证码的历史端点，本版本也**不宣称已实现自动 API 下载**。
- 登录、手机号验证、滑块、验证码、风控或接口数据变化时停止自动处理，让用户在平台完成验证或提供 PDF；不尝试规避验证。浏览器下载的响应也必须在命名为 PDF、上传飞书前通过 `scripts/download_validator.py`。若浏览器只能先存文件，先存隔离暂存目录、不改名正式 PDF；验证失败删除该临时文件，不写入案卷。
- 只读取用户这次明确授权的案件与链接；不得将匿名链接猜成其他案件的文书。重复标题和重复上传须从案号、正文与原件查重。
