# 字段映射与接入

## 字段

使用配置中指定的保全表。先实时读取字段并确认表 ID。字段或表结构变化时，记录不匹配之处。数据登记阶段保持已有公式和填色规则。

| 飞书字段 | 处理 |
| --- | --- |
| 主字段（当前可能名为 `文本`） | 自动设为 `案号 + 保全物短名`，一项一行 |
| `案号`、`法院`、`裁定作出日期` | 文书正文提取；日期为真实日期类型 |
| `实际保全日期` | 有明确实施日用实施日，否则自动填裁定日并标记待核 |
| `保全对象类型` | 严格限银行存款、动产、不动产、其他财产权；依真实字段类型写选项 |
| `保全物详情` | 保留能识别财产的原文短段，不改变账户/权属等关键字 |
| `保全期限` | 若保留此数值列，写从起算日到测算日的实际日数，不能固定写 365/730/1095；若文书另定较短期限，依文书记载换算 |
| `期限单位` | 若保留，写 `天`；本列对到期计算并非必要，可在确认没有公式依赖后隐藏或删除 |
| `期限依据` | 若保留，写 `文书明确期限` 或 `分类上限暂算`；可在确认无依赖后隐藏或删除 |
| `保全到期日` | 根据起算日加适用日历年得到的管理用测算日期，或文书明确写明的更短届满日期。写为飞书日期，不把字符串写进日期列 |
| `剩余天数`、`预警状态` | 飞书已有公式，完全不写；由原表自动计算和填色 |
| `是否 已经续保` | 保持现有值；新增行默认未勾。仅用户明确确认实际续保完成后才勾选旧行 |
| `新保全到期日` | 不再写，续保独立新行；确认无依赖后可隐藏或删除 |
| `核验状态` | 当前单选只有 `已核验` / `未核验`；有任何待核事项选 `未核验`，原因在回复中说明；证据足以核实实施日、期限与财产信息后才选 `已核验` |
| `来源文书` | 原件的飞书附件或真实可访问链接；如果当前字段是附件类型，直接上传原件作为附件，不往附件列写 URL 字符串 |
| `原文摘录` | 与 `保全物详情` 重复时不再写；确认无依赖后可隐藏或删除 |
| `唯一标识` | **保留并隐藏**。按案号、裁定文书号码、裁定日、措施、财产可识别描述生成稳定标识，避免同文书重复上传造成重复行；敏感完整案号不写入明文标识，可使用 SHA-256 前 24 位。旧记录空值时还需查案号/措施/财产相近项，不能仅按标识判重 |

不能确认字段类型、缺少必需字段或飞书附件能力不可用时停在提取结果，说明所缺前提；不得临时创建另一份 Excel。`来源文书` 如果是外部链接且确需保存超链接，应新增专用超链接字段，不能把现有附件列强行当作 URL 列。

## 跨平台执行

使用当前会话已授权的飞书集成或官方 Lark CLI。具体连接和定向变更按 [平台接入](agent-setup.md) 执行。各环境分别检查读写权限、原件附件能力和写后回读。
