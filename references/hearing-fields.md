# 已知字段与待补字段

映射适用于本次配置的开庭与案件节点表。先列出该表实际字段、类型和选项，并核对与保全表的分工。下面的字段名是建议映射。

| 现有字段 | 用法 |
| --- | --- |
| `记录名称` | 主字段，推荐“案件名称｜开庭 YYYY-MM-DD HH:mm”；缺案件名用案号，不伪造 |
| `案号`、`法院` | 从原文提取，案号保留原格式 |
| `文书类型`、`节点类型` | 按飞书已有选项写入；节点类型选择开庭对应选项 |
| `节点时间`、`地点` | 传票载明的开庭开始时间（日期时间字段）与地点 |
| `当事人` | 双方和多方当事人全部平等记录，不分角色；第三人另列 |
| `唯一标识` | 判重；稳定地对应案号和同一场开庭，改期沿用原行 |
| `来源文书` | attachment；原件上传并关联 |
| `核验状态`、`备注` | 依原有选项写核验情况；变更、缺值等写备注 |
| `飞书日程ID` | 日历实际创建成功后写回，防重复 |
| `原文摘录` | 开庭日期、地点或改期部分的短摘录 |
| `联系电话`、`承办法官` | 文书载明可填；不需要可留空 |

## 可补充的字段

| 新列名 | 飞书类型和选项 | 原因 |
| --- | --- | --- |
| `案件名称` | 文本 | 可读标题，“甲诉乙＋案由” |
| `程序类型` | 单选：`简易`、`普通` | 仅当文书有依据时选 |
| `第三人` | 文本 | 和所有其他当事人分开 |
| `预计结束时间` | 日期时间 | 仅作为创建日程时的排程结束，传票无结束时可用开始后 2 小时估算并在备注说明 |
| `冲突状态` | 单选：`冲突`、`正常`、`待核` | 技能跨行比对后写状态；红色填色和消息以该列触发 |
| `冲突描述` | 文本 | 写冲突案号、日期及“时段重叠”或“同日不同时间”；以实时读取字段为准 |

`预计结束时间` 如不想单独建列，也可以在飞书日历自动化里设固定时长；但使用前必须验证日程创建动作确实支持，不能假定该功能存在。字段名称和选项完全匹配才写对应字段，不调整现有公式。

## 飞书侧可自行配置的功能

1. **填色**：在开庭表的表格视图点 `填色`，新增规则：整行（或至少节点时间单元格）、字段 `冲突状态`、条件 `等于`、值 `冲突`、颜色红。保存规则；用测试行验证红色显示，避免只是文本写“红”。
2. **冲突通知**：在目标表配置自动化，记录首次进入冲突状态时向指定对象发送消息。可用状态跃迁触发；只支持宽泛触发时，通过独立发送状态和回读防止重复。向指定用户或群发测试消息前核对收件人及授权。
3. **日历**：选用已授权、可回读的日历。用一份合成传票验证时区、起止时间、事件 ID 回写和重复导入。改期后核对原事件已更新；取消测试日程按 ID 定向处理。日历动作失败应保留已核验的表格记录和待同步状态。

飞书帮助中心的[多维表格按钮说明](https://www.feishu.cn/hc/zh-CN/articles/297830150616-%E5%85%B3%E4%BA%8E%E5%A4%9A%E7%BB%B4%E8%A1%A8%E6%A0%BC%E4%B8%AD%E6%8C%89%E9%92%AE%E7%B1%BB%E5%9E%8B%E7%9A%84%E8%AF%B4%E6%98%8E)介绍表内按钮可用于更新记录、发送通知；日程如果表内找不到适用动作，可用[飞书开放平台创建日程接口](https://open.feishu.cn/document/server-docs/calendar-v4/calendar-event/create)或执行环境已授权的日历工具。具体菜单和动作以用户当前飞书页面为准，不预设版本都支持。
